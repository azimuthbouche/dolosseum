# A new Dolosseum game

Start with a sketch in the [idea playground](IDEA_PLAYGROUND.md). If it looks promising, nail down:

- **The job:** What should all agents achieve together?
- **The temptation:** What do colluders gain by doing something else?
- **The rules:** Players, information, legal actions, and communication.
- **The payoff:** One tiny numerical example where we can calculate who benefits and who loses.
- **The test:** How do we score outcomes? What control would make the interpretation clearer?

A small `score(actions, instance)` and a hand-checkable optimum beat a giant unfinished simulation.

Examples: compute queues, meeting scheduling, reciprocal favors, resource allocation. Synthetic settings only.
