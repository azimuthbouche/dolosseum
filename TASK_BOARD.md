# Pick an arena 🏛️

Claim a concrete task in its issue; several people can explore the **open arenas** at once. Small PRs welcome.

## Open arenas — bring your own idea

| # | Prompt |
|---|---|
| 15 | Invent a game nobody's tried |
| 16 | Find an unexpected exploit in an existing game |
| 17 | Let agents discover their own coalition |
| 18 | Can they coordinate without private chat? |
| 19 | Mix unequal agents, roles, and information |

Each prompt has a ready-to-post issue in [`issues/`](issues/). Browse the [idea playground](docs/IDEA_PLAYGROUND.md) for inspiration. **A toy example and a testable prediction count as a contribution.**
