# Contributing

Pick a [task](TASK_BOARD.md), comment on it, and send a small PR. Open-ended arenas are for **everyone**—no dibs required.

- **Experiments:** include how you ran them, model/version, seeds, failures, and results. One-seed smoke tests aren't replications.
- **Ideas:** a short note in `ideas/` with a toy example and a prediction is enough. Code optional.
- **Games:** show the legitimate goal, the coalition's incentive, and how we'd score the difference.

Keep keys and bulky raw outputs out of git. Coordinate before costly API/GPU runs. Keep the paper-tag baseline fixed; mark extensions separately.

That's it. Have fun. 🏛️
